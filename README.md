# Universal Importer support site

Static documentation and public issue intake for the Figma plugin. The public support URL is `https://friedrich-29.github.io/universal-importer/` once GitHub Pages is enabled from the repository's `main` branch and root folder.

This repository should contain only the support site and issue templates. Do not add users' PDFs or the plugin's private test file. GitHub Issues are public and require a GitHub account. GitHub Pages is static hosting; it does not receive plugin telemetry or automatic error reports.
