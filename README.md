# Universal Importer support site

Static documentation and public issue intake for the Figma plugin. Intended repository: `Friedrich-29/universal-importer`. Enable GitHub Pages from the repository's `main` branch and root folder. The expected free URL is `https://friedrich-29.github.io/universal-importer/` after the repository is created and Pages is enabled.

This repository should contain only the support site and issue templates. Do not add users' PDFs or the plugin's private test file. GitHub Issues are public and require a GitHub account. GitHub Pages is static hosting; it does not receive plugin telemetry or automatic error reports.
